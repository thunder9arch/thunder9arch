## 🎯 What I do

I like the layer **below** the demo: sharding, replication, rate limiting, failure handling, observability. My projects start with a hard systems problem and end with a measurable result, not just "it works on my machine."

- 🧱 Build distributed systems from first principles (consistent hashing, heartbeats, read repair)
- 🤖 Build infrastructure for LLM APIs (rate limiting, cost control, protection against abuse)
- 🎨 Ship polished, installable frontends when a project needs a human face
